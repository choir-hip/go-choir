# --- NOT on this list, so COUNTED against the ceiling (non-voice native code: debt, or a platform seam). Only the audio session, the microphone, speech and the on-device models are voice
# (owner, CLAUDE.md: "only voice is native"). Each of these has its reason, and none of them is voice:
#   Choir/MailSeal.swift            a platform cipher (CryptoKit AES-GCM; Exact's crypto.subtle refuses AES), key kept natively in the Keychain. Android owes it in Kotlin. Was on this list as an exception.
#   Choir/ChoirSignIn.swift         only sign-out now (the local key goes, the revoke is sent); signing in is shared code (app-signin.ts, @exact/passkeys). The voice stages above read the key Exact's secret store keeps in the Keychain (KeychainKeyStore).
#   AutoradioModule+Platform.swift  the platform seam: the audio session owner (voice), the console log file the proof reads, the system's background time. The session owner is voice and could be split out.
#   ProofKey.swift                  the simulator-only proof key (a test seam, compiled out of device builds).
#   Conversation.swift              the turn engine's record of the question, the answers and their words (state of the voice turn; a candidate for the voice list when it is shown to be only that).
#   RunSheetTypes.swift, RadioBridge.swift, BarState.swift, ChoirApp.swift, ChoirClient.swift, RadioProgramme.swift, the rest of the counted files: see the checker's list (scripts/check-autoradio-native-boundary).

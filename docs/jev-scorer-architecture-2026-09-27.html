5 · Obligation state machine

Scoring state is independent of outcome state: a down scorer never turns confirmed into unresolved. One retry owner (guest worker); the cell's model loop never retries. Auth failure suspends provider dispatch — no silent fallback, no self-scoring.

6 · The dialectic — what the positions actually disagreed about

PositionVerdictCore claim / fatal flaw
A — hidden harness outboxcomponent Complete coverage, structural isolation; but invisible to the self-development loop that must tune it. Survives as the settlement mechanism, not the contract.
B — cell calls Score()rejected Optional actuation → selection-biased calibration corpus; cheapest winning strategy is never calling it. Result-returning variants breach the boundary outright.
C — authored lifecycle, runtime settlementendorsed Agent authors typed precommits and evidence-bearing resolves (module verbs = RLM contract); the resolve commit mints the obligation automatically; results supervision-only. Unanimous composition across both rounds.
D — scorer is a desklater Cross-desk prediction markets (monitor desk precommits on executor) — the memo's own supervision topology; a fifth desk is not a minimal slice.
E — offline batch evallater Scores derived from ledger snapshots by autoresearch — no live signal; a complement to the spine, not the spine.
The real fault line: obligation ownership, not transport (every position uses the same wire). Also settled: contract legibility belongs in the question spec and scorer policy — Go code the engineering desk can change — not in a score-triggering verb.

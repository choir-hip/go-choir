Precommitment fabric + Jev scoring — architecture

Internal working diagram · 2026-09-27 · rev 3 (post unified-collapse review) · mutation class RED · pending owner ratification

Round-3 consensus correction: "every inter-desk utterance is a packet" over-collapses. The substrate unifies (one envelope, one authority path, one atomic wake-outbox fold, one inbox projection) but two persisted families survive: desk-authored packets (addressed obligations/mail) and ledger records (predictions, resolutions, scores). Scores are runtime-authored facts — they never enter the desk-mail path because AssembleCellInbox injects every channel message into cell context unfiltered: a score packet addressed to a desk is an evaluator-gaming channel by construction.

1 · Topology — three author classes, one substrate

Cells author via tray-staged verbs; the reducer commits post-cell; all wakes ride the durable actor-wake outbox (minted in the canonical fold, `lifecycle.go:2088–2128`, drained by the 500ms projector). Wake is a hint — delivery is the durable pending-item drain at activation start.

6 · Obligation state machine

Scoring state ≠ outcome state: a down scorer never turns confirmed into unresolved. Cell's model loop never drives retries. Exactly-once persistence, disclosed at-most-once-paid billing.

7 · What the three rounds decided

Every utterance a packet?amendedOne envelope/authority/wake substrate; two persisted families. Scores never become packets — delivery path injects into acting context unfiltered.

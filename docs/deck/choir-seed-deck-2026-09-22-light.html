How do humans supervise work at agentic scale?

CHOIR — the automatic computer.
choir.news01
Problem

Agentic work has outgrown
the supervisory interface.

  • Work now runs faster and longer than a human can watch.
  • People wake up to answers they cannot inspect.
  • Chat does not scale to many agents, many people, continuous work.
A chat thread is not a workbench. The interface is a live, updated state document.
choir — the automatic computer02
Solution

The work itself
is the interface.

Agents update a versioned document — the authoritative state of the work. Humans read it and edit it. An edit is a new version, and steers what happens next.
  • Models and agents are swappable. The state is yours.
Language is for intent. The document is for steering.

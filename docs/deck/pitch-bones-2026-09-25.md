## Slide 02 · Problem

**Kicker:** Problem
**Title:** Agentic work has outgrown the supervisory interface.
**Rule**
**Points:**
- Computation now runs faster, longer, and across more parallel threads than any human can watch.
- Chat was designed for two humans taking turns; it collapses as a supervisory interface for autonomous agents.
- People wake up to answers they cannot inspect and transcripts they cannot steer.
**Keyline:** A chat thread is not a workbench. A feed is not a perspective.
**Foot:** choir — the automatic computer · 02

---

## Slide 03 · Solution

**Kicker:** Solution
**Title:** The work itself is the interface.
**Rule**
**Body:** Agents update a versioned document — the authoritative state of the work. Humans read that state directly and edit it. An edit is a new version, and steers what happens next.
**Points:**
- Precommitment records make autonomous runs trustworthy, auditable, and self-improving.
- Models and agents are swappable. The state is yours.
**Keyline:** Language is for intent. The document is for steering.
**Foot:** choir — the automatic computer · 03

## Slide 06 · The Category

**Kicker:** The category
**Title:** Every person, team, and organization gets an automatic computer.
**Rule**
**Grid 3:**
- **Atomic Unit:** One persistent, self-driving computer per person, team, org, or autonomous agent.
- **Generations:** Mainframes (thousands) → PCs (~2B) → Smartphones (~4.5B) → Automatic Computers (>1B near term, 10B+ long term).
- **Category Math:** 50k prosumer publishers + 15k team seats = $54M ARR from a microscopic fraction of instances.
**Keyline:** We don't need to own the category. We need to be the default neutral workbench.

## Slide 07 · Market & Business Model

**Kicker:** Business model
**Title:** Open-source core. The network is the business.
**Rule**
**Grid 3:**
- **Open-Source Core:** Free self-host. Builds developer trust, distribution, and non-negotiable enterprise data sovereignty.
- **Hosted Convenience:** $35/mo prosumer publishers; $100/seat/mo team async meeting desks that steer 24/7 background agents.
- **The Network Asset:** Publishing network (paywall take-rates) + permissioned API queries over the aggregate, provenance-linked corpus.
**Keyline:** We don't sell computers. We build the network where perspectives compound.

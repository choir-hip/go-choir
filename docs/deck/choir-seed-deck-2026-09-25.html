Solution

The work itself
is the interface.

Agents continuously update a living, versioned document representing the current state of truth. Humans read that state directly and edit it.
  • Editing is steering: an edit creates a new version and redirects agent trajectories.
  • Precommitment records make autonomous execution trustworthy and auditable.
Language is for intent. The document is for steering.

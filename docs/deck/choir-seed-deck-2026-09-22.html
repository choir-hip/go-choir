choir.news01
Problem

AI can work for hours.
The work gets trapped in chat.

Long-running work produces sources, tasks, decisions, and changes. A transcript is a poor place to manage that.
  • People wake up to answers they cannot inspect.
  • Agents repeat work because project memory is weak.
  • Teams cannot easily trust, share, or revise the result.
A chat thread is not a workbench.
choir — the automatic computer02
Solution

Choir gives agents a shared workbench.

The durable object is the work itself — not the assistant, not the chat history.
Human
→
Shared work state
→
Agents + tools
→
World
  • Agents come and go. Work persists.
  • Models can be swapped. State remains yours.
  • The interface shows what changed, not just what was said.

Given the tape and the code version, the same computer reconstructs anywhere. State is intentional — every byte has a reason.

The machine

Desks do the standing work.
Casts do the bounded work.

Desks — persistent actors
Management, engineering, research. One live activation each, fenced and serial. A desk persists because it is the learner — its value is its calibration history.
Casts — async sub-RLMs
rlm.spawn is an admission event, not a call. The result arrives later as a message event. No parent ever blocks; the tape carries the return channel.
Cells — in-cell carrier
One Go REPL envelope per activation. Typed choir.* functions stage intents; one reducer commits them. No JSON tool tray, no output repair.
Delivery — state heads
"Delivered" means "in the actor's state head," committed atomically. Pending work is a projection, not a ledger. The retry is the lease.

Learning records — PICL

Predict. Resolve. Revise.
The tape remembers the miss.

Every cast can carry expected — a committed prediction the result event resolves. Prediction, observation, discrepancy, revision: a first-class record with provenance edges, folded onto the object graph by an async Curator desk.

A desk's fan-out is calibration data about its own decomposition. A model call with an expected shape is per-model calibration — what model selection should learn from.

Supervision, built in

The human is the constitution,
not the approval queue.

Capabilities, not vibes
Mechanically restricted grants. Delegation and exercise are different bits. Irreversible effects demand stronger evidence and durable receipts.
Correction is an ordinary write
A rival proposal is forked; policy-governed consensus selects a head; new evidence falsifies a settlement. No special machinery — the tape does it.
Mutation classes
Green to black. Red surfaces — canonical writes, provider calls, run acceptance, deploys — carry full ceremony: conjecture, evidence class, rollback path.
Effects OFF until proven
Self-development effects stay off until the computer makes one real change to itself — legibly, durably, on staging. By design, not by delay.

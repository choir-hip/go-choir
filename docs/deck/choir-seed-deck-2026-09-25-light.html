Problem

Agentic work has outgrown
the supervisory interface.

  • Computation runs faster, longer, and across more parallel threads than any human can watch.
  • Chat was designed for two humans taking turns; it collapses as a supervisory interface for autonomous agents.
  • People wake up to answers they cannot inspect and transcripts they cannot steer.
A chat thread is not a workbench. A feed is not a perspective.
choir — the automatic computer02
Solution

The work itself
is the interface.

Agents update a versioned document — the authoritative state of the work. Humans read that state directly and edit it. An edit is a new version, and steers what happens next.
  • Precommitment records make autonomous runs trustworthy, auditable, and self-improving.
  • Models and agents are swappable. The state is yours.
Language is for intent. The document is for steering.
